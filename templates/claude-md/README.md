# قالب‌های CLAUDE.md

`CLAUDE.md` حافظه‌ی پروژه‌ی Claude Code است — در شروع هر جلسه خوانده می‌شود. این قالب‌ها همان ساختاری را
پیاده می‌کنند که در [دوره‌ی ۰۱](https://vibecodeschool.com/courses/claude-code-vibe-coding) آموزش داده
می‌شود: **پشته‌ی فناوری ← دستورها ← قواعد خانه ← دام‌ها ← توافق کاری.**

| قالب | برای |
|------|------|

| [`mobile-expo.CLAUDE.md`](./mobile-expo.CLAUDE.md) | اپ‌های Expo / React Native (بیلدهای EAS) |
| [`monorepo.CLAUDE.md`](./monorepo.CLAUDE.md) | مونوریپوهای Turborepo / pnpm-workspace |

## نحوه‌ی استفاده

1. نزدیک‌ترین قالب را با نام `CLAUDE.md` در ریشه‌ی مخزنتان کپی کنید.
2. هر خطی را که درباره‌ی پروژه‌ی شما درست نیست پاک کنید. **پاک کردن گام مهم است** — ایجنت به این فایل
   اعتماد می‌کند؛ حافظه‌ی غلط از نبود حافظه بدتر است.
3. از آن به بعد، با یک عادت نگهش دارید: *ایجنت را دو بار درباره‌ی یک چیز اصلاح کردید؟ آن اصلاح یک خط در
   CLAUDE.md می‌شود.*

یا یکی را از روی یک فرم بسازید: [سازنده‌ی CLAUDE.md](https://vibecodeschool.com/demos/claude-md-generator).
